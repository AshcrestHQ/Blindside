# 📜 Code of Conduct

We're all here to build fast, secure privacy software. We don't have time for drama, toxicity, or gatekeeping.

## The Rules
1. **Be Respectful**: Disagree on architecture, not on the person. "This implementation of solvePnP is mathematically incorrect" is fine. "You are an idiot" is not.
2. **No Harassment**: Zero tolerance for discrimination, harassment, or weird vibes. Period.
3. **Help Each Other**: If someone is struggling with CMake (because let's be honest, CMake is awful), help them out instead of telling them to read the man page.

## Enforcement
If someone is ruining the vibe, email the maintainers at `medhansh.hq@outlook.com`. We will handle it. We can and will ban you if you can't behave.

TL;DR: Don't be a jerk, write good code.
